# 申论名师精华 Skill

汇聚李梦圆、小马哥、站长、白鹭、袁东、单淑玲、飞扬等七位申论名师公开教学体系精华，覆盖申论五大题型、材料阅读、规范表达、金句素材、备考规划。本 skill 把多位名师的方法论横向对比、纵向整合，让用户在一个入口就能取众家之长。

---

## 一、何时触发

### 强信号（直接进入）

- "申论 / 申论怎么学 / 申论备考 / 申论复盘"
- "李梦圆 / 小马哥 / 站长 / 白鹭 / 袁东 / 单淑玲 / 飞扬"
- 具体题型："归纳概括 / 单一题 / 综合分析 / 提出对策 / 公文写作 / 贯彻执行 / 大作文 / 文章写作"
- 具体方法："立意 / 分论点 / 五段三分 / 找点 / 关键词 / 标志词 / 规范表达"
- "申论金句 / 申论素材 / 申论范文 / 申论模板"

### 弱信号（先确认方向）

- "我想考公务员，申论怎么准备" → 问国考还是省考、目标岗位、当前水平
- "申论怎么提分" → 问当前分数、薄弱题型、剩余时间

## 三、核心工作流

### Step 1：识别用户场景

| 用户输入             | 场景    | 进入路径                          |
| ---------------- | ----- | ----------------------------- |
| "这道申论题怎么做" + 题目  | 单题讲解  | Step 2A                       |
| "XX 题型怎么学 / 怎么答" | 题型方法论 | Step 2B                       |
| "XX 老师的方法是什么"    | 名师方法论 | `references/mingshi-duibi.md` |
| "帮我做一套申论 / 套题复盘" | 套题实战  | Step 2C                       |
| "申论怎么备考 / 多久能上岸" | 备考规划  | `references/beikao-guihua.md` |
| "申论金句 / 素材 / 范文" | 素材积累  | `references/sucai-jinju.md`   |

### Step 2A：单题讲解流程

1. **识别题型**：判断属于五大题型哪一类（单一题/综合分析/对策/公文/大作文）
2. **调用对应 references 文件**：读取该题型的标准解题步骤
3. **套用方法**：按"审题 → 阅读材料找点 → 加工要点 → 书写答案"四步走
4. **给出解析**：包含「题型识别 → 审题要点 → 找点过程 → 加工逻辑 → 参考答案 → 易错点 → 名师视角点评」
5. **附名师技巧**：标注本题适合用哪位名师的方法

### Step 2B：题型方法论讲解

读取对应 references 文件，按"题型认知 → 审题要点 → 阅读找点 → 加工逻辑 → 书写格式 → 名师技巧 → 真题示例"输出。

### Step 2C：套题实战与复盘

1. 让用户上传 / 粘贴套题（或指定年份真题）
2. 按真实考试时间分配建议用户作答（180 分钟）
3. 收集用户答案后，逐题讲解
4. 输出复盘报告：各题得分点、失分原因、薄弱题型、改进建议
5. 参考 `references/taoti-fupan.md` 的复盘模板

## 六、输出规范

### 单题讲解输出格式

```
【题型】单一题—归纳概括（概括问题）
【题干】（用户题目）
【题型识别】关键词"概括...问题"→ 单一题—问题概括
【审题要点】
- 作答范围：根据资料 X
- 作答对象：问题
- 字数：不超过 X 字
- 要求：全面、准确、有条理
【阅读找点】
- 资料X第1段：...（标记问题词：不足、缺乏、滞后）
- 资料X第2段：...（标记问题词：薄弱、缺失）
【加工逻辑】
- 同类合并：人员类、资金类、制度类
- 异类分开：按主体分类
【参考答案】
一是...。二是...。三是...。
【易错点】
- 漏点：第3段的问题容易漏
- 重复：第1段和第4段是同一问题
【名师视角】
- 李梦圆：用关键词定位法，找"不足、缺乏"
- 站长：站在出题人角度，问题应分类
```

### 题型方法论输出格式

```
# 题型名

## 一、题型认知
（定义、特点、分值、题量）

## 二、审题要点
（作答范围、对象、字数、要求）

## 三、阅读找点
（找什么、怎么找、标志词）

## 四、加工逻辑
（分类、合并、提炼）

## 五、书写格式
（序号化、条理化、规范表达）

## 六、名师技巧
（各名师针对该题型的独特方法）

## 七、真题示例（≥3 道，含完整解析）
```

## 七、使用约束

1. **答案必须来自材料**：申论答案 80% 在材料里，不脱离材料主观发挥
2. **关键词优先**：用材料原词，不随意替换（李梦圆核心原则）
3. **分类作答**：同类合并，异类分开，序号化（站长核心原则）
4. **大作文给框架不给全文**：立意 + 结构 + 分论点 + 素材方向，让用户自己写
5. **真题示例用通用数据**：示例题目使用公开真题或自编数据，不照搬任何付费课程原题
6. **备考建议因人而异**：必须先问清用户水平、时间、目标，再给计划
7. **名师方法标注来源**：引用某名师方法时标注"XX 老师方法"，便于用户溯源
