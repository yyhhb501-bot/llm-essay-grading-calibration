## 效果示例

> **场景一：单一题（归纳概括）讲解**

```
用户 ❯ "根据给定资料，概括我国当前城市治理中存在的主要问题。"

申论.skill ❯ 【题型】单一题—归纳概括（概括问题）

【题型识别】关键词"概括……问题"→ 单一题—问题概括
【审题要点】
- 作答范围：根据给资料
- 作答对象：城市治理中的问题
- 字数：不超过 200 字
- 要求：全面、准确、有条理

【阅读找点】
① 资料第2段：执法方式简单粗暴（问题词：粗暴、缺乏规范）
② 资料第3段：公共服务设施不完善，停车难、如厕难（问题词：不完善、难）
③ 资料第4段：流动摊贩管理陷入"整治—反弹"循环（问题词：循环、反复）
④ 资料第5段：垃圾分类推行困难，居民配合度低（问题词：困难、低）

【加工逻辑】按治理领域分类：
- 执法类：方式简单粗暴 → 执法规范不足
- 设施类：停车难、如厕难 → 公共服务短板
- 管理类：摊贩整治反复 → 长效管理缺失
- 环境类：分类推行困难 → 环保意识薄弱

【参考答案】
一是执法不规范。执法方式简单粗暴，缺乏规范标准。
二是设施不完善。停车、如厕等公共服务存在短板。
三是管理不到位。流动摊贩管理陷入"整治—反弹"循环，缺乏长效机制。
四是环保意识弱。垃圾分类推行困难，居民配合度不高。

【名师视角】
- 李梦圆：用关键词定位法，找"粗暴、不完善、难、循环、困难"
- 袁东：用前置句提炼，"一是执法不规范。二是设施不完善。……"
```

> **场景二：综合分析题**

```
用户 ❯ "给定资料中提到了'邻避效应'，请你谈谈对它的理解。"

申论.skill ❯ 【题型】综合分析—词句理解

【解题框架】是什么—为什么—怎么办

【找点过程】
① 含义：资料说"邻避效应"指居民反对建在自家附近的公共设施
② 表现：垃圾站、变电站等设施选址时，居民担心影响生活而抗议
③ 原因：信息不透明 补偿机制缺失 信任不足
④ 对策：加强沟通 合理补偿 科学选址

【参考答案】
"邻避效应"是指居民因担心公共设施（如垃圾站、变电站）对自身健康、房产价值等产生负面影响而进行抵制反对的社会现象。
该现象产生的原因有：一是信息公开不充分，居民对设施安全存疑；二是利益补偿机制缺失，居民感到不公；三是政府公信力不足，沟通不到位。
因此，应加强信息公开透明，建立合理补偿机制，开展社区协商共治，从"邻避"走向"邻利"。

【名师视角】
站长四步分析法：是什么—为什么—怎么办—怎么样
```

> **场景三：大作文立意**

```
用户 ❯ "给定资料中提到'治'慧，请以此为话题，自选角度，写一篇文章。"

申论.skill ❯ 【审题三步】

① 题干拆解："治"→ 治理、管理；"慧"→ 智慧、方法
② 材料主旨：基层治理、城市管理、乡村治理中的智慧方法
③ 确定立意：以治理之"慧" 成善治之效

【五段三分结构】

┌─ 开头（150字）：引名言 + 点明"治"与"慧"的关系 + 亮明中心论点
├─ 分论点1（250字）：治之慧，在于科学决策，尊重规律
│   └─ 论证方向：城市管理要遵循发展规律，不搞"一刀切"
├─ 分论点2（250字）：治之慧，在于以人为本，回应民需
│   └─ 论证方向：从群众需求出发，提升公共服务温度
├─ 分论点3（250字）：治之慧，在于多元共治，凝聚合力
│   └─ 论证方向：政府主导 + 社会协同 + 公众参与
└─ 结尾（150字）：总结升华 + 展望

【素材方向】
- 经济/治理："枫桥经验"、党建引领基层治理
- 民生：老旧小区改造、适老化改造
- 生态：河长制、垃圾分类
- 科技：数字政府、"一网通办"

【名师视角】
- 站长：出题人视角，题干"治慧"→ 治理智慧，结合材料谈方法论
- 白鹭：拆题法，拆出"治"和"慧"两个关键词，分别展开
```

## 题型速查

| 题型            | 核心方法                   | 题量（国考） | 分值      | 目标用时     |
| ------------- | ---------------------- | ------ | ------- | -------- |
| **单一题（归纳概括）** | 关键词定位 + 要素分类 + 前置句提炼   | 1–2 题  | 10–20 分 | 20–25 分钟 |
| **综合分析题**     | 是什么—为什么—怎么办（站长四步分析法）   | 1 题    | 15–20 分 | 25–30 分钟 |
| **提出对策题**     | 问题反推 + 原因反推 + 五大对策来源   | 0–1 题  | 15–20 分 | 20–25 分钟 |
| **公文写作题**     | 格式 + 内容 + 语言（15+ 文种速查） | 1–2 题  | 20–25 分 | 30–35 分钟 |
| **大作文**       | 立意三步法 + 五段三分 + 白鹭分论点四法 | 1 题    | 35–40 分 | 50–60 分钟 |

### 核心方法库

| 方法         | 适用场景  | 操作步骤                  |
| ---------- | ----- | --------------------- |
| **关键词定位法** | 单一题找点 | 找问题词/原因词/影响词/对策词，定位要点 |
| **四步分析法**  | 综合分析  | 是什么—为什么—怎么办—怎么样       |
| **拆题法**    | 大作文立意 | 拆题干关键词，逐词分析，确定方向      |
| **五段三分式**  | 大作文结构 | 开头 → 分论点1/2/3 → 结尾    |
| **大框架法**   | 大作文论证 | 观点+分析+案例+总结的段落结构      |

## 答题策略

### 推荐做题顺序

```
材料阅读（5min通读）→ 单一题（25min）→ 综合分析（30min）→ 对策题（25min）→ 公文写作（35min）→ 大作文（60min）
```

### 时间分配原则

1. **先看题目再看材料**：先通读题干，划关键词，再带着问题读材料
2. **单一题保分**：分值虽不高但最容易得分，必须拿满
3. **大作文留足时间**：50–60 分钟，留 10 分钟构思立意和结构
4. **字迹工整**：申论有卷面分，每道题控制好字数，不超格
5. **序号化作答**：一、二、三、四 或 一是……二是……三是……

### 阅读标记法

```
问题词   ✗         —— 不足、缺乏、滞后、薄弱、缺失
原因词   →          —— 由于、因为、源于、与……有关
影响词   ★  /  ☆    —— 正面：促进了、提升了；负面：导致、造成
对策词  ✓          —— 应、要、通过、加强、完善
```

## 功能特性

### 覆盖题型

**单一题（归纳概括）**：概括问题、原因、影响、做法、特点、变化

### 输出规范

每道题的讲解包含：

- **题型识别**：关键词 → 判断题型（单一题/综合分析/对策题/公文/大作文）
- **审题要点**：作答范围、作答对象、字数、特殊要求
- **阅读找点**：材料原文 + 标记方法（关联词/关键词/首尾句/观点句）

- **参考答案**：序号化、规范表达、字数控制
- **易错点**：漏点、重复、分类错误、超出字数

## 注意事项

* **答案必须来自材料**：申论答案 80% 在材料里，不脱离材料主观发挥
* **关键词优先**：用材料原词，不随意替换（李梦圆核心原则）
* **分类作答**：同类合并，异类分开，序号化（站长核心原则）
* **大作文给框架不给全文**：立意 + 结构 + 分论点 + 素材方向，让用户自己写
* **易错点必给**：每道题、每个题型都要附易错点提醒
* **真题示例用通用数据**：使用公开真题或自编数据，不照搬付费课程原题
* **备考建议因人而异**：必须先问清用户水平、时间、目标，再给计划
* **名师方法标注来源**：引用某名师方法时标注"XX 老师方法"，便于用户溯源
