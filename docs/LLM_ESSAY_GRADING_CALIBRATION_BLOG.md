# 申论评分校准的实现与验证方法

2026-10-27 修订：此前此文将模拟样本、预设噪声实验和未核实的用户量描述为真实成果，相关结论撤下。维护者确认没有真实人工评分和使用规模记录。

## 问题与实现

申论反馈需以题目、材料和考生作答为依据；材料缺失时省略评分。LLM 原始分数可能存在偏差，但本项目尚未以真实数据证明偏差模式或校准效果。

现实现 `calibration/pipeline.py`：显式接收人工标签及来源；按题目留出测试集；Ridge 标准化与参数选择限制在训练题目内，固定参数的梯度提升树作为对照。以未见题目的原始分、Ridge 和 GBDT 计算 MAE、0–100 整数尺度 QWK，辅以消融和分组偏差报告。网站仅在真实标签审核后接入模型，默认不进行统计改分。

## 复现与判断

按 [校准说明](../calibration/README.md) 运行。`--demo` 仅产生明确标记的模拟功能演示。真实数据需独立标注，保留标注口径、时间、评分量表和来源，防止重复作答或题目泄漏。更严格的研究仍需标注者一致性、充分样本、置信区间与外部题目验证。

重复评分方差只能通过同一作答的实际重复结果计算；没有重复观测则不可给置信度，较小方差亦不能证明准确。历史脚本通过人为设置两个噪声标准差得出的改善不是校准效果证据。

## 目前可以陈述什么

已实现申论批改网站和监督式校准实验管线。尚不能陈述固定 MAE/QWK 改善、300 多用户或 2,400 多篇真实提交；没有运行生产自动周评估和重训。数字应在真实实验完成后，从保存的输入与报告引用。
