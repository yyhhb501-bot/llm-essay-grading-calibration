## 本机运行

使用 Node 22.13+（本次验证 Node 24.19）。在项目目录运行：

```powershell
$env:REGISTER_INVITE_CODE = '自行设置注册邀请码'
node site-server.js
```

打开 `http://127.0.0.1:8787`。邀请注册后可使用已有服务端模型配置，或登录后在设置里填写自己的 Key。若未设置 `REGISTER_INVITE_CODE`，本机会优先使用原共享模型配置的口令，再使用 `ACCESS_CODE`；都没有时禁止注册。

账号和服务端会话存于 `.runtime/accounts.sqlite`（并可能有 SQLite 的 `-wal`、`-shm` 文件），包含密码派生值及会话令牌摘要，没有明文密码。该目录不通过静态网站提供，也不应放入前端、Git 或公开备份。`SLZ_AUTH_DB_FILE` 可单独指定数据库位置。备份宜在服务停止后复制数据库及必要的 WAL 文件，或使用 SQLite 的在线备份工具。

若通过反向代理提供 HTTPS 网址，Node 默认不信任转发头。仅在可信代理下显式设置 `TRUST_PROXY=1`，并让后端只监听 `127.0.0.1`、由代理正确传递原 Host 和 `X-Forwarded-Proto: https`；不要把信任转发头的后端裸露到公网。会话在 HTTPS 网址使用 Secure Cookie，非本机的明文 HTTP 不能注册或调用模型。

## Cloudflare 账号版与后续更新

账号库使用 D1，绑定名必须为 `AUTH_DB`。原模型 Secret 与配置继续使用；不要复制密钥到网页代码。

1. 首次上线已创建 `shenlun-accounts`。后续更新复用它，不要重复创建或替换已有账号库。新环境创建命令为 `npx wrangler d1 create shenlun-accounts`。
2. `wrangler.toml` 已配置真实 D1 ID，绑定为 `AUTH_DB`，迁移目录为 `migrations`。新环境须填自己的真实 ID，不要用占位 ID 发布。
3. 迁移本地开发数据库：`npx wrangler d1 migrations apply shenlun-accounts --local`；先用 `npx wrangler dev` 检查真实 Workers 运行时。
4. 核对目标账号、数据库和域名后执行远程迁移：`npx wrangler d1 migrations apply shenlun-accounts --remote`。
5. 可通过 `npx wrangler secret put REGISTER_INVITE_CODE` 设置新的注册邀请码；不设置则沿用现有 `ACCESS_CODE`。旧口令不能独立授权模型请求。
6. 完成前端构建并核对配置后 `npx wrangler deploy`，再用真实公网浏览器验证注册、登录、刷新、模型调用、退出、两账号隔离。登录涉及的会话 Cookie 不在不同域名间自动共享。

已在 Node SQLite、D1 适配层及本地 workerd/D1 运行时验证，并完成远程 D1 迁移与公网验收。回退参考版本为 `776c5410-0faf-4498-b2cd-8bec1316b597`；回退 Worker 不应删除账号库。官方步骤参考：[D1 migrations](https://developers.cloudflare.com/d1/reference/migrations/)、[Worker Binding API](https://developers.cloudflare.com/d1/worker-api/)。

## EdgeOne 与单文件

旧 `deploy-edgeone/` 匿名发布包未接入本次持久化账号后端，不能只覆盖静态页面就视为完成账号上线。本次账号版的可选后端是本机 Node 或绑定 D1 的 Cloudflare Worker。

单文件 HTML 是另一份构建产物；网页新逻辑以 `site/` 的源码为准。需要同步单文件时运行 `node tools/bundle-single-html.js`。离线 `file:` 自带 Key 模式没有远程账号，不能作为网站账号登录的验证。

## 验证与运维

`node tools/test-auth.mjs` 通过 56 项账号检查；`node tools/test-auth-client.cjs` 通过 13 项浏览器存储隔离检查。`node tools/test-site-api.js`、`node tools/test-site.js`（14 项）、`node tools/test-worker-opencode.js` 检查登录后的原有模型转发，模型均为本地模拟服务。本地 workerd/D1 另通过 13 项检查。生产版本仍需远程 D1、真实域名与目标用户网络检查。

会话有效期 7 天；退出会在服务端撤销当前会话。修改密码会撤销该账号原有会话并为当前浏览器签发新会话。本次没有短信、邮箱验证、支付、管理员后台或远程找回密码流程。数据库不可用时账号接口返回明确错误，模型请求拒绝执行。
