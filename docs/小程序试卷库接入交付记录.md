审计详情为 `docs/小程序试卷数据审计.json`，包含排除记录和缺分值题号。生成器只读取原文件，没有改动爬虫正文、原始网页、答案或采分点。

“可载入”仅指材料和题目结构通过检查，不是逐字核对原始卷面的认证。回忆版、第三方来源和原文件使用说明均保留；没有将内容标成官方原卷或官方答案。

## 2. 小程序改动

- 首页“试卷练习”进入新题库页，分为“收录试卷”和“离线改编示例”。
- 收录列表支持年份、地区、关键词筛选，每次展示 20 套并可继续加载。
- 登录后通过固定站点的账号接口逐卷读取；正文不打入小程序主包，缓存只在当前进程、当前账号上下文中保留最近 3 套。
- 材料可展开全文；题目显示实际作答要求，未识别分值有明确提示。
- “去作答”带入所选题干、作答要求和整卷全部材料，题型为可调整的自动建议，不按猜测裁掉资料。保留已有草稿时先确认是否替换。
- 不自动载入第三方采分点或参考答案，避免将未核验提取结果当作官方依据。
- 切换账号清理跨页预填引用，旧账号或旧展开请求返回后不能覆盖当前页面。
- 原生主包新增轻量索引约 70KB；原始全文、答案、采分点等大目录加入打包排除项。

## 3. 后端与发布

- 独立表：既有 `shenlun-accounts` D1 中的 `practice_papers`，字段 id、sha256、body。没有改写账号表或删除用户。
- 迁移：`worker/migrations/0002_practice_papers.sql`，仅创建独立试卷表。
- 导入：`.agent/mp-papers-import.sql`，371 条可重复执行的按 ID upsert；没有 DELETE、用户表操作或清空数据库。
- 接口：GET `https://shenlundawang.asia/api/mp/papers/{id}`，使用小程序 Bearer 认证；正文响应为 private/no-store，匿名请求返回 401。
- 已发布 Worker 版本：`09d3f300-5859-4bb0-8d05-2e6ba8f604ca`。
- 前一版本：`b20f89cf-ca5e-4960-bb16-87de48de6d8b`；回退 Worker 无需删除试卷或账号数据。

本地 `site/js/app.js` 等存在其他未上线改动。本轮未将它们混入发布：`tools/prepare-mp-paper-release.js` 从当前线上保存了可读取的现有静态文件，并生成 `.agent/mp-papers-release/wrangler.toml` 供本轮后端发布。Wrangler 报告读取 96 个资源条目且无静态文件更新；发布后 6 个网站关键文件 SHA-256 与快照相同。

后续仅更新后端时应重新核对线上静态快照并使用对应发布配置。直接使用 `worker/wrangler.toml` 会包含本地 `site/` 的其他未上线内容；不能把本次后端发布视为那些网站改动已经发布。
