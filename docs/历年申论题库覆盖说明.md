# 2020—2026 申论题库与答案状态

## 卷子全文导入（进行中）

来源：公开真题库 gwy.gkzhenti.cn 卷子页（其内容来源标注 fenbi、部分为网友回忆版）。每套卷的给定材料全文与作答要求已结构化解析。

- 目录：`data/paper-catalog.json`（376 套，2020—2026，含国考与 33 个省区市）
- 全文：`data/papers-full/{paperId}.json`（materials + questions），索引 `data/papers-full/index.json`
- 原始 HTML 存档：`output/crawl-raw/`
- 抓取工具：`node tools/crawl-paper-content.js`（断点续爬）
- 调度：Windows 计划任务 `ShenlunCrawlNightly`（每晚 00:05 触发 `tools/run-crawl-once.js`：白天守卫不爬、只爬到 07:30、未爬完自动顺延下一夜、全部完成后自动注销任务）；`tools/register-crawl-task.ps1` 可重新注册；`tools/run-crawl-tonight.js` 为手动兜底入口。每夜日志在 `output/crawl-night-YYYY-MM-DD.log`。

**抓取节奏**：该站对爬虫的公开要求为「大于 1 分钟/1 次、建议 0:00–6:00」，违反会临时封禁、多次封禁进永久黑名单。2026-10-11 上午曾因频率过快触发临时封禁（约 45 分钟后自动解封），此后改为凌晨窗口 65 秒/卷低速爬取，全部剩余卷数预计一夜内完成。进度看 `data/papers-full/index.json` 的 summary。

## 采分点锚点库与批改接入（2026-10-11 新增）

为批改评分系统提供结构化校准数据（方法论证见会话记录 P0 方案）：

- **抽取**：`node tools/extract-answer-points.js --region=国考` 把挂载的答案文章用本地配置的 GLM（.runtime/shared-model.json）抽成题目级采分点（题干/分值/题型/各机构要点/评分标准），存 `data/answer-points/{paperId}.json`。可断点重跑（--force）。已知问题：约两成长文首次解析失败（JSON 截断/未转义引号），重试修复可部分挽回，失败卷标记 done=false 可补跑。
- **接入**：`node tools/sync-site-papers.js` 把 papers-full 全文与 answer-points 同步进 `site/js/vendor/`（papers/ 与 answer-points/ 目录 + papers-index.js 懒加载索引）。网站真题目录（#/papers）对已导入的卷子出现「选题作答」按钮：展开题目列表 → 「预填到批改」自动填 题型/题干/对应材料/非官方参考答案（多机构分组，带来源声明）。
- **同题多记录选优**：同一卷子不同来源文章可能给出同题号的不同记录（含错挂卷），预填时按题干相似度+分值一致选最优一条。
- **边界**：参考答案一律标注非官方；锚点数据仅供训练比对，不冒充官方采分表。

## 社交平台答案爬取（2026-10-11，省考全量扫描完成）

知乎专栏文章游客可读、站内搜索需登录（用户已微信登录；登录后站内搜索有频率限制，限流时改用百度 site:zhihu.com 检索，两者互补）。共提取知乎答案内容 **160 篇、约 58.4 万字**，存于 `data/answers-crawled/`（逐批 JSON + `index.json` 索引/覆盖矩阵/省份与卷别标注）：

- **国考 2020—2026 三卷别全覆盖**（约 46 篇）：「万字精讲」系列（给定资料+逐题解析）、「申论各家答案汇总」多机构对比、东汇达等多家参考答案。
- **省考 30 个省区市有直接命中**（约 96 篇）：联考 2020—2026 逐年、江苏/浙江/广东/山东/北京/上海/四川/福建/深圳/天津/重庆/湖北/湖南/河南/陕西/广西/黑龙江/吉林等；福建含 2026 通用卷三题（附评分标准）与 2022 省市卷。西北/西南部分小省（新疆/宁夏/青海/甘肃/海南/内蒙古）依赖联考文章覆盖，直接命中少。
- 已知折扣：相当比例单题答案文章正文为**图片**（提取不到文本，批次 JSON 中 ok:false），省考尤甚；部分文章是网盘引流页（文本很短）。
- 检索工具链：百度/知乎站内搜索定位 → 浏览器逐篇打开 → `.Post-RichTextContainer` 提取 → 逐批存盘。扩展或重跑可直接复用会话中的 scanBaidu 流程。
- 来源与作者逐篇记录；均为机构/考生分享的参考答案，**非官方**，仅供学习比对。

小红书（用户提供的「不败小熊」账号「近7年国考申论答案对比合集」）：站内搜索与笔记内容需登录，未登录浏览器只能看到登录墙。已留登录页待用户扫码后可继续爬取；该笔记内容为图片版答案对比（疑似网盘 PDF 预览），即使登录也需处理图片/网盘下载。
