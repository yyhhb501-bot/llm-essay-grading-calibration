# 网站账号登录第一版

## 已确认的体验

用户名和密码注册、登录；注册时核对邀请码，之后不再要求填写共享访问口令。所有网页模型请求必须有有效的服务端会话，旧访问口令不能绕过登录。账号在同一个浏览器中使用各自的模型设置、历史和计划；既有未归属账号的数据保留，不自动归到新账号。第一版不承诺跨设备同步记录。

## 文件分工与顺序

1. 后端由 ZCode 实现：`server/auth.mjs`、`server/auth-local.cjs`、`site-server.js`、`worker/worker.js`、`worker/migrations/0001_accounts.sql`、`tools/test-auth.mjs`。Node 使用本机 SQLite（Node 22.13+），Cloudflare Worker 使用 D1，复用账号和会话逻辑。不得修改模型供应商配置和密钥，不得上传、部署。
2. 后端通过独立复核后，Antigravity 只实现 `site/index.html`、`site/css/site.css`、`site/js/auth.js`、`site/js/store.js`、`site/js/api.js`、`site/js/app.js` 中的登录界面与接入。保持原有批改、题库、陪练功能及请求结构。两个工作者顺序工作。
3. Codex 负责接口约定、基线备份、实际差异复核、必要修复、浏览器检查和部署说明。检查时网站没有 Git 仓库，先用 `.agent/auth-baseline/` 保存原文件，再建立本地代码基线 `440378f`，通过实际 Git 差异复核。工作者实际运行情况和接手记录见 `.agent/handoff.md`。

## 账号接口约定

- `GET /api/auth/session`：`{ok:true,authenticated:boolean,user:{id,username}|null}`。Cookie 不存在或过期时返回未登录，数据库未配置返回 503。
- `POST /api/auth/register`：JSON `{username,password,inviteCode}`，注册成功 201，自动建立会话，返回 `{ok:true,user:{id,username}}`。用户名 3–24 字符，限中文、英文、数字、下划线和短横线，进行 NFKC 及英文小写归一化；密码 8–128 字符，不自动 trim。邀请码来自 `REGISTER_INVITE_CODE`，兼容站主原有 `ACCESS_CODE`（本地共享配置口令可作注册邀请码）。没有邀请码配置时拒绝注册。
- `POST /api/auth/login`：JSON `{username,password}`，成功 200 并建立会话；用户名不存在和密码错误均返回相同的 401 错误。
- `POST /api/auth/logout`：撤销当前服务端会话并清除 Cookie，重复退出可成功。
- `POST /api/auth/password`：JSON `{oldPassword,newPassword}`；更新后撤销该账号所有原会话，签发当前浏览器的新会话。
- 错误 JSON 为 `{error:string,code?:string}`，不包含密码、密码哈希或会话令牌。
- `POST /api/chat`：先核验会话，再转发现有模型请求；未登录为 401；不能通过共享访问口令或自带 Key 绕过登录。自带 Key 仍可在登录后使用。

## 服务端约束

使用带随机盐和迭代次数的 PBKDF2-SHA256 密码派生（100000 次，兼容 Workers Web Crypto）；随机会话令牌仅放 HttpOnly、SameSite=Lax Cookie，HTTPS 添加 Secure，服务端只保存令牌摘要，7 天过期。持久化的登录/注册节流；修改密码和退出立即撤销会话。所有变更请求核验同源 Origin，限制 JSON 请求体；错误不得暴露凭据。SQLite/D1 必须参数化查询并保证用户名唯一。配置缺失或数据库不可用必须明确拒绝，不能降级成口令模式。

## 验收

- 注册、重复注册、错误密码、会话恢复、退出、过期会话、密码修改及旧会话撤销；邀请码错误和未配置；没有登录及仅携带旧口令的模型请求被拦截。
- 跨域请求和超大/无效 JSON 被拒绝；连续错误登录被节流；数据库中无明文密码和会话令牌；服务重启后账号保留。
- 同一套迁移在 Node SQLite 和 D1 适配测试中通过。所有外部模型测试使用本地桩，不消耗真实模型额度。
- 桌面与 390px 手机浏览器：注册登录能完成、错误可读、刷新保持登录、退出立即隐藏原账号内容、切换账号无历史或模型 Key 泄漏、无横向滚动；登录后批改仍可调用模拟模型。
- 所有交付均标明本地验证与线上发布状态。Cloudflare D1 创建、迁移和正式部署需在实现复核完成后另行执行；EdgeOne 旧匿名部署尚无本方案账号存储，不能把仅替换静态文件视为完成登录上线。
