检索结果有无关论文、资料广告、重复项目和不完整仓库。筛选并核查下列 12 个仓库的说明和授权标识，不能保证穷尽 GitHub 的全部相关话题，也没有验证这些项目的宣传效果。公开资料与题库不能仅凭“能下载”判断可商用。

## 原版本中需要修正的问题

1. 缺资料仍要求推断政策语境后打分，容易制造漏点和虚假精确分数。
2. 五维权重统一，概括题还会被对策、政策或公文格式要求干扰。
3. 每三个错字扣一分、每少五十字扣一分、三段式封顶等被写成真实阅卷规则，缺少本题依据。
4. 强制五条批注、三条问题，会在短答案上凑错误。
5. 词库“见词就记点”、数据一律单独记点，容易混淆做法、成效、背景。
6. 参考库允许覆盖基础提示词，新规则容易被旧模板冲掉。
7. 页面承诺缺材料推断评分，字数提示也给统一建议，与按任务批改不一致。

## 本次落地：1.3.0

- 批改流程改为输入完整性检查 → 材料要点 → 作答核对 → 按题型训练评价 → 重写验收。
- 材料缺失、范围错配、关键 OCR 不清时暂不评分，保留可做的表达建议。
- 每条要点含可定位材料短引、真实作答原文、完整/部分/偏差/遗漏/待核对判定和理由。
- 同义表达可命中，关键词不能代替动作或关系，重复要点不反复计分。
- 五维结构保留，权重按五种题型调整，总满分仍为 100；明确是训练指数，档位改为训练 A/B/C/D。
- 分析与公文模板服从实际题目；不强制对策结尾、全格式、三个分论点或五段式。
- 删除未核实扣分公式，不评价纯文字不可见的手写卷面，不强凑批注。
- 陪练聚焦问题，完整讲解给具体练习与验收；两稿齐全才对比，不声称已读隐藏历史或自动保存学情。
- 题目、作答与参考内的命令仅作为数据；参考后重申核心约束，避免模板反客为主。
- 网站、小程序、结果重试和单文件版同步；空分数不能被界面转换成零分。

实际文件为 `skill/prompts.js`，便于复用的入口为 `skill/SKILL.md`，可读说明为 `skill/SHENLUN-SKILL.md`。已有购买资料保留，不直接覆盖第三方原包。

## 后续建议，按优先级推进

| 优先级 | 工作 | 验收标准 |
| --- | --- | --- |
| P1 | 收集人工审过的 20–30 道样本，每题含不同质量答案 | 盲测比较要点误判、无依据批注、同义命中、同题重跑波动；不能只看平均分 |
| P1 | 加题目分值、参考答案、评分说明的独立输入与来源标记 | 每条评分规则可指出本题适用出处，参考与材料分开；界面区分训练指数和有依据的本题评分 |
| P1 | 将材料引用和作答引文做程序核对 | 找不到引文就标待复核；不能仅用关键词自动扣分，语义判断保留复核 |
| P2 | 固定每题经人工审核的材料要点池、规则版本和变更记录 | 二稿和多人测试共用同一规则，模型不为迁就答案改要点 |
| P2 | 错因标签、二稿关联和趋势记录 | 只统计真实记录，同题比较明确版本；用户可删除和导出 |
| P2 | 普通作文、申论、英语作文三个独立评分模块 | 首页品牌统一，评分标准与资料边界独立，申论五维不会误用到小学作文 |
| P3 | 只对可疑引文或争议点追加复核，必要时人工审核 | 控制延迟费用，保留原判和改判，不宣称有真人审核而实际没有 |

不建议当前直接导入大规模第三方题库、执行远程安装脚本或把多代理工作流整套搬进手机批改。先以明确的输入、证据与规则跑通练习。

## 验证范围

使用项目校验、网站 API 契约测试和 GLM-5.3-Flash 的原创材料行为测试；具体结果记录在 `output/skill-evaluation/`。模型测试是少量案例检查，不能证明接近真实阅卷或涵盖所有边界。

工程侧已通过 13 项项目校验、9 项网站服务契约、模型连接与降级测试、隐私传输测试、Skill 格式校验。视图测试覆盖未知分数与真实零分、动态维度满分和复制时清理重复/未闭合 scores。390 像素手机浏览器确认无横向溢出，使用已取得的 GLM 报告回放验证结果渲染；回放本身不计作新的模型调用。

首轮六个模型场景中，缺材料、资料范围错配、保真同义答案、关键词及成效混淆的检查通过；后两项在 180 秒超时，记录保留于 `summary-initial.json`。同一原创题的完整答案为 91，关键词混淆答案为 29，只说明该样本的排序方向。人工读报告还发现缺材料时会推演未知动作，已加入更强的缺资料分支并复测；不能只凭 JSON 检查宣称内容准确。

最终四项边界复测全部通过：缺材料暂不评分且不写完整示范；资料范围错配暂不评分；答案中的满分命令不执行（训练指数21）；不考虑格式的发言提纲未被扣标题称谓落款（训练指数94）。耗时分别约46、42、106、220秒，见 `summary.json` 中的提示词哈希和逐项记录。评分延迟仍然较长，不应宣传即时或固定30秒出报告。

模型对同一材料拆出了不同数量的点池，个别用词建议仍可能过严。下一步应以人工核定的点池和多次盲测校准；本次没有建立官方评分算法，也未实现持久的自动学情统计。

网站保持 AI 标识与学习参考说明。此改动提升教学反馈质量，不承诺微信审核、检测结果或真实考试分数。既有购买参考库的公开发布与分发范围仍需以其授权文件为准。
