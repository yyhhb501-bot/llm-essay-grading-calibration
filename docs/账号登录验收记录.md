## 浏览器实际操作

使用 Playwright CLI 独立浏览器，在 `http://127.0.0.1:18991` 的隔离预览服务上操作，预览账号库是 `output/playwright/auth-preview.sqlite`，没有使用或覆盖站主真实账号数据库和模型配置。

1. 错误邀请码被拒绝；正确邀请码注册后自动进入批改页，显示当前用户名。
2. 实际点击范例、真题预填和开始批改，模拟报告完成并入该账号历史；刷新仍保持登录并可回看。
3. 为账号 A 写入历史、模拟 Key 和计划，退出后用账号 B 注册：B 的三项数据为空，A 的内容不显示，旧版 `slz_history` 仍保留。
4. 多标签页退出时，另一标签页立即重新加载到登录页，不继续展示旧报告。
5. 错误登录密码显示统一中文错误；修改密码对话框完成操作并保留新会话。
6. 模拟退出接口 503，页面不声称已退出并提供重试提示。模拟模型接口 401 时保留账号登录状态，正常显示模型密钥错误。
7. 模拟账号服务 503，个人页面隐藏、显示错误和重新连接按钮；移除模拟故障后点击重新连接，登录表单恢复，未泄漏个人页面。
8. 浏览器脚本看不到 HttpOnly 会话 Cookie。390×844 登录页的内容宽度为 390，无横向溢出。
