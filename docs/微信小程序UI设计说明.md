## 1. 整体视觉规范与 Design Tokens

基于“专注申论、克制现代、长文高可读性”的教育工具定位，小程序整体摒弃了旧版偏沉重的拟物及衬线字体风格，全面转向 **高对比度 Retina 现代无衬线视觉系统**。

### 1.1 核心色彩系统 (Color Tokens)

| Token 名称 | 色值 | 用途与视觉心理 |
| :--- | :--- | :--- |
| `--paper` | `#F6F7F9` | 页面全局背景色。纯净护眼浅灰白，减少长时间阅读材料的视觉疲劳 |

### 1.2 字体与排版规则 (Typography)

- **字体族声明**：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "Helvetica Neue", "Microsoft YaHei", sans-serif`，彻底移除正文中的宋体/Georgia 等衬线字体，消灭移动端边缘发虚问题。
- **分数与数据字体**：`font-family: "DIN Alternate", -apple-system, BlinkMacSystemFont, sans-serif`，数字等宽利落。
- **字阶与行高**：
  - 一级主标题（Hero / 页面核心）：`34rpx - 36rpx`，粗体 `font-weight: 700`，行高 `1.4`
  - 二级模块标题（卡片标题）：`30rpx - 32rpx`，半粗 `font-weight: 600`
  - 正文字号（材料、题目、批改报告）：`28rpx - 29rpx`，长文行高固定为 `1.7 - 1.8`，字间距 `0.5rpx`
  - 辅助说明与标签：`24rpx - 26rpx`
  - 弱提示与时间戳：`22rpx - 24rpx`

### 1.3 容器、圆角与触控规范 (Layout & Components)

- **水平安全边距**：全局页面 `padding: 24rpx 28rpx`。
- **圆角体系**：
  - 主卡片：`--radius: 20rpx`
  - 按钮与输入控件：`--radius-sm: 12rpx`
  - 筛选胶囊与状态标签：`--radius-pill: 999rpx`
- **触控目标高度**：主要按钮高度 `88rpx - 96rpx`（满足移动端 ≥44px 黄金触控标准），次级胶囊与点击行高度 ≥ `72rpx`。
- **微阴影层级**：`box-shadow: 0 2rpx 12rpx rgba(0, 0, 0, 0.03)`（轻量悬浮，无脏黑感）。

## 2. 核心公共组件规范

### 2.1 按钮系统 (`app.wxss`)

- **`.btn-primary`**：全宽/胶囊主行动按钮，珊瑚橙渐变背景（`linear-gradient(135deg, #FF6B35 0%, #FF5722 100%)`），白字，带微橙色光晕投影。具备禁用态（`background: #F2F3F5; color: #86909C`）和按压微缩态（`transform: scale(0.99)`）。
- **`.btn-ghost`**：浅灰微框按钮，`background: #FFFFFF; border: 1rpx solid #E5E6EB; color: #4E5969`。
- **`.btn-danger`**：危险操作按钮，`background: #FEF2F2; color: #DC2626; border: 1rpx solid rgba(220, 38, 38, 0.2)`。

### 2.2 表单控件 (`input`, `textarea`, `picker`)

- **外框**：统一采用 `1rpx solid var(--line)`，圆角 `var(--radius-sm)`，背景纯白。
- **聚焦态**：高亮边框 `border-color: var(--cinnabar)`，带微橙聚焦扩散光影。
- **多行文本域**：设置 `line-height: 1.6; font-size: 29rpx`，内置右下角/顶部实时字数统计。

### 2.3 隐私授权弹窗 (`components/privacy-dialog`)

- 完全保留微信官方 `open-type="agreePrivacyAuthorization"` 与 `bindagreeprivacyauthorization="onAgree"`。
- 背景采用深色半透明微模糊遮罩（`rgba(0,0,0,0.45)`）。
- 弹窗卡片使用现代纯白圆角设计，协议外链采用浅橙胶囊底色，主按钮与取消按钮具备高触控对比度。

## 3. 分页面设计与实现明细

### 3.1 首页 (`pages/index`)
- **视觉焦点**：顶部保留“作文批改大人”与申论专项辅助定位，核心首屏突出“开始批改”Hero 大卡片，配带行动描述与箭头指引。
- **功能四宫格**：将“真题库”、“解题陪练”、“备考计划”、“模型设置”收录为现代白底轻卡片，去除低俗 Emoji，强化排版层级。
- **每日金句**：下移至辅助区域，纯白卡片加左侧橙色装饰条，保证首屏不被语录过度挤占。
- **最近记录**：直接展示真实标题、答题字数/得分胶囊、相对时间与摘要截断；空态引导点击去写第一篇申论。

### 3.2 批改提交页 (`pages/grade`)
- **表单顺序**：严格遵循“题目与类型 → 给定资料 → 我的作答 → 提交批改”。
- **题型选择器**：弹窗列表式单选，胶囊展示当前题型，清晰区分“归纳概括”、“提出对策”、“综合分析”、“贯彻执行”与“大作文”。
- **必填与选填**：采用高辨识度的精致微胶囊 Badge（`.badge-required` 橙底，`.badge-optional` 灰底）。
- **作答与拍照 OCR**：
  - 作答输入区内置“📷 拍照识别”微胶囊按钮与实时字数计数器。
  - 拍照 OCR 支持识别中动画反馈与取消操作，识别失败后弹窗清晰保留原有错误并提供恢复。
- **防呆与提交流程**：未配置 API Key 时明确引导前往设置；无材料时友情提示评分精度；提交按钮具有“批改中...”禁用锁和文字反馈。

### 3.3 批改报告页 (`pages/result`)
- **标题与性质说明**：顶部明确提示“五维训练指数（非官方成绩）”，恪守合规边界。
- **核心数据看板**：采用 `DIN Alternate` 大号数字排版呈现综合得分，附带题型与字数详情，无分数时按真实状态展示。
- **三段式选项卡**：`批改总览`、`逐条朱批`、`升格示范`，平滑切换。
- **Markdown 结构化排版**：全面优化标题、引用块（`.md-blockquote` 浅橙底加粗竖线）、列表项与强调文本（`.md-strong` 暖橙粗体加高亮底纹），解决长篇批改报告拥挤密集的痛点。
- **底部行动栏**：清晰收纳“复制报告（附带 AI 生成合规声明）”、“重新批改”和“调整模型”。

### 3.4 个人中心 (`pages/mine`)
- **真实数据看板**：双列网格展示本地真实批改篇数、平均训练指数与陪练对话数，不伪造天数与排名。
- **功能分组列表**：
  1. “学习与工具”（历史记录、备考计划、模型与 Skill 设置）；
  2. “隐私与数据安全”（服务与隐私说明、撤回数据传输同意、清空历史记录、删除全部本地数据）；
  3. “关于与说明”（版本号、技术说明）。
- **纯 CSS 箭头与触控反馈**：消除图片图标依赖，危险操作（清空/删除）采用红字警示与二次确认 Modal。

### 3.5 解题陪练 (`pages/chat`)
- **身份清晰化**：将“名师”文案统一为“AI 解题陪练 · 实时生成”，气泡头部标注模型身份。
- **对话气泡**：用户消息右浮动，浅灰背景高对比；AI 消息左浮动，纯白卡片配合结构化排版。
- **底部输入 Dock**：固定在屏幕底部并自适应 iPhone 底部安全区（`safe-area-inset-bottom`），集成多行自动伸缩输入框与快捷发送按钮。
- **快捷提问胶囊**：提供“分析给定资料逻辑”、“提炼本题核心得分点”等申论专项预设。

### 3.6 内置真题页 (`pages/papers`)
- **手风琴交互**：套题卡片支持平滑折叠展开，展开后清晰呈现题号、分值、题目正文与材料节选。
- **醒目标记**：保留“改编练习（非原卷）”标识与说明。
- **一键带入作答**：点击“去作答”即可将材料和题目全量带入批改页，链路闭环。

### 3.7 备考计划页 (`pages/study`)
- **表单选择器**：四项核心参数（基础水平、每日时长、目标岗位、剩余周数）采用统一卡片表单。
- **按周打卡系统**：生成后以清晰的任务卡片呈现各阶段目标，本地勾选持久化打卡进度。

### 3.8 模型与 Skill 设置 (`pages/settings`)
- **新手三步指引卡片**：直观引导新用户“选择服务商 → 填写 API Key → 测试连接并保存”。
- **服务商快捷预设**：SiliconFlow、DeepSeek、智谱、阿里云等一键填入网关地址与推荐模型。
- **高级 Skill 折叠区**：将申论朱批核心 Prompt、字数限制等专家配置收纳，保持主界面清爽。
- **API Key 遮蔽**：输入框采用 `password` 属性，保障演示及录屏时不泄露密钥。

### 3.9 历史记录页 (`pages/history`)
- **多维度筛选 Bar**：全部、批改记录、对话记录胶囊平滑切换。
- **列表卡片**：左侧通过珊瑚橙/金橙竖线区分记录类型，右侧标注得分与时间，支持长按删除单条记录与右上角一键清空。

### 3.10 服务与隐私说明页 (`pages/service`)
- **层次分明的合规卡片**：涵盖“AI 辅助学习边界”、“当前模型接收方与域名”、“传输数据范围”、“本地管理与撤回”。
- **微信隐私协议查看**：保留调起微信原生隐私保护指引按钮。

## 4. 账号系统设计规范（待小程序接口接入）

> **状态标记**：`[待小程序接口接入 / DRAFT]`  
> **说明**：当前原生微信小程序为纯本地配置与本地存储架构。网站版（`site/`）已实现用户名密码与邀请码体系。为满足未来小程序端接入需要，在此提前提供完备的前端交互设计与接口设计规范。**本阶段未挂载入小程序正式可用导航，避免误导用户。**

### 4.1 页面视觉设计稿规范

1. **登录界面 (`pages/login/login`)**：
   - 顶部品牌标识：珊瑚橙渐变 Logo，副标题“申论批改大人 · 账号登录”。
   - 表单项：
     - 用户名输入框（支持字母、数字与下划线，带一键清空图标）。
     - 密码输入框（带明文/密文切换小眼睛图标，默认密文）。
   - 主按钮：“登录”（珊瑚橙 `.btn-primary`，未输入完整时置灰禁用，点击进入 loading 态）。
   - 底部辅助导航：“没有账号？立即注册”、“暂不登录，使用本地模式”。
2. **注册界面 (`pages/register/register`)**：
   - 表单项：
     - 用户名（4-20 位）。
     - 登录密码（不少于 6 位）。
     - 确认密码（实时校验两次输入一致性）。
     - 邀请码（预留选填项，根据部署配置支持无码或必填模式）。
   - 协议勾选：阅读并同意《服务与隐私协议》单选框。
   - 主按钮：“立即注册并登录”。
3. **已登录个人中心态 (`pages/mine/mine` 账号接入后)**：
   - 顶部增加账号信息卡片：显示用户名、注册时间、登录设备状态。
   - 账号管理组：增加“修改密码”、“退出登录”操作项。

### 4.2 接口与会话接入技术标准建议

- **网络请求鉴权**：
  - 微信小程序内不支持标准浏览器 Cookie 自动携带跨域机制，推荐采用 `Authorization: Bearer <token>` 方式。
  - Token 保存在本地 `wx.setStorageSync('slz_auth_token')`。
  - 每次请求通过统一封装的 `utils/request.js` 在 Header 中注入该 Token。
- **本地与云端数据迁移策略**：
  - 用户首次登录时，系统应提示：“检测到本机有 X 条未同步的批改记录，是否合并至当前账号？”
  - 避免粗暴覆盖或丢失用户在单机状态下的做题成果。
- **退出登录规则**：
  - 清空内存及本地 Storage 中的 `slz_auth_token` 与用户资料缓存；
  - 明确提示用户是否保留或清空该设备上的作答历史。
