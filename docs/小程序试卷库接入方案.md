# 小程序试卷库接入方案

日期：2026-10-20。用户明确要求“核对数据并接入小程序”。

## 已核实数据

- 目录 380 条；全文目录 374 个分卷 JSON（另有 index.json）。
- 371 个分卷同时具备非空材料和题目，合计材料 1,855 篇、题目 1,414 道。39 道题未识别出正分值，保持为空。
- 3 个分卷材料／题目为空，另 6 条目录没有全文；均不进入可作答列表。
- 371 个分卷与 site/js/vendor/papers 对应副本逐 JSON 内容相同。271 套目录标注或标题显示回忆版；全部保留来源和使用说明。
- 这些检查仅证明本地数据结构和副本一致，未逐卷对照原网页核验文字、缺页、题数或解析准确性，不能标注“官方完整原卷”。

## 设计与接口

原 3 套摘要改编练习保留为独立“内置示例”。新增“收录试卷”列表，展示实际数量、年份／地区筛选、关键词搜索和分页；一次只加载选中的一套，不把 7.8MB 原始 JSON 放入小程序主包。

复用现有 D1 与账号后端：新增独立 `practice_papers` 表保存分卷正文与摘要值，原账号表与用户数据不变。GET `/api/mp/papers/{id}` 使用小程序 Bearer 会话，仅返回所选分卷，不公开匿名批量下载接口。网站界面与已有静态资源不在本次发布范围。

原生主包仅含轻量索引 `data/mp-papers-index.js`。索引包括 id/title/year/region、材料／题目数、回忆版标记，不包含正文、参考答案、密钥或用户信息。

分卷读取须处理：未登录、失效、离线、接口未上线、缺失／不合法 JSON、切换过快、账号切换、重试与载入状态。缓存只保留当前账号本次进程最近几套，不保存整库到本机。

选择某题后将“题干＋原作答要求”和整卷全部材料载入批改页，明确由题干确定适用材料范围，不用不可靠的正则擅自裁掉资料。不自动填入采分点或参考答案，不把第三方提取要点当官方答案。更换已有作答需确认。

## 文件所有权与顺序

1. ZCode/OpenCode：`tools/build-mp-papers.js`、`utils/paper-library.js`。离线核对生成轻量索引、审计报告和独立表导入 SQL；固定源的原生分卷请求与缓存；明确 build、permission allow，禁部署／秘密读取／无关修改。
2. Codex 集成：`server/paper-library.mjs`、`server/auth.mjs`（只读鉴权参数）、`server/auth-local.cjs`、`worker/worker.js`、`worker/migrations/0002_practice_papers.sql`、`site-server.js`、`app.js`、`utils/auth.js`、`pages/papers/papers.js`、`pages/grade/grade.js`、首页入口文案、打包排除项。
3. Antigravity：仅 papers 页 WXML/WXSS、grade 页来源卡 WXML，按功能阶段约定事件和字段实现。工作者不并发修改工作区。
4. Codex 独立审查实际改动、核对数据与运行相关语法／构建检查；记录原生环境限制。

若配置的工作者无法认证或启动，确认停止与释放锁、记录 `.agent/handoff.md` 后 Codex 接手，保留现有数据和 UI。既有账号、密钥、历史、网站源码及原始网页不覆盖、不删除。

## 可核对交付

- 离线审计报告列出总数、空卷／无全文清单、缺失分值，不修改爬虫原始数据。
- 轻量索引、可重复生成的导入 SQL、原生题库页和带入作答流程。
- 导入仅新增／更新独立试卷表，不改账号表；部署前先核对 SQL 和 Worker dry-run。
- 全文数据导入与 Cloudflare 后端发布仍需用户在看到实际结果后明确指示，微信小程序上传不在本次授权内。
- 小程序 request 合法域名为既有账号域名；开发者工具端口与真机验收按实际环境记录，不用 HTML 预览代替。
